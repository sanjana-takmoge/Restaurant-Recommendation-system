# 🍽️ Restaurant Recommendation System

This is a simple Restaurant Recommendation System built using Machine Learning and Flask. It suggests restaurants based on user preferences and available data.

## 🚀 Features
- Recommend restaurants based on input
- Data preprocessing using Pandas and NumPy
- Machine learning model using Scikit-learn
- Simple web interface using Flask

## 🛠️ Tech Stack
- Python
- Flask
- Gunicorn
- Pandas
- NumPy
- Scikit-learn
